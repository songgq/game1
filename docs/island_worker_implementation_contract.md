# 小岛地图与工人系统实施合同

> 状态：用户已确认，直接指导开发  
> 日期：2026-08-23  
> 优先级：本文件对岛屿地图和工人系统的规定覆盖旧升级文档中的冲突内容；不修改战斗地图与战斗工人。

## 1. BattleMap 与 IslandWorld 严格分域

- `BattleMap`继续使用独立的22×40、32px战斗网格，只服务战斗寻路、弹道、模拟和回放。
- `IslandWorld`固定为720×1280。经营`IslandLandGrid`独立为21×35、CellSize=32、Origin=(24,80)。
- 每块农田固定占用一个1×1 LandGrid单元，按网格正向摆放，不使用45度斜置的等距投影占位。
- 岛屿AStar、占用表、任务路径、TileMap配置和版本不得读取或复用BattleMap网格；两者最多复用美术纹理。
- 15块土地为3×5，每块完整7×7=49格。自然海岸只绘制在LandGrid视觉外沿，不得删除、阻塞或改变任何土地格。

## 2. 地块与初始状态

- 初始解锁1～4；5～15全部显示云雾、锁且可点击查看前置地块、PlayerCharacter等级和材料。
- 只允许5→6→…→15顺序解锁。
- 1号地开局必须存在唯一、`READY`且可用的`StorageChest`。
- 首版没有自由布局、建筑移动、建筑等级或建筑升级。

## 3. 实体边界与操作

- 岛上唯一移动劳动实体是`IslandWorker`；`PlayerCharacter`只保存等级/技能树，不生成地图节点；岛上不存在`HeroObjects`。
- 小岛页默认选中1号工人；玩家通过左侧工人图标切换当前工人，再点击树、矿、农田或制作建筑，将任务加入该工人的独立FIFO队列。最多展示5名工人。
- 右侧横向显示所选工人的非终态队列，每组任务使用小图标表示并提供取消按钮。排队任务立即取消；ACTIVE任务完成当前安全原子循环后取消。
- 点击已解锁且可行走的空LandGrid格加入`MOVE_TO_CELL`；点击交互对象则加入对应生产任务。普通空地点击不显示“几号地已解锁”说明。
- 被某名工人加入非终态队列的资源/农田显示淡蓝色占用框，其他工人不能重复安排；同一工人连续点击同一资源仍只合并队列展示，底层保持多次完整循环。
- 客户端按任务阶段显示现有工人动画：去程持对应工具、工作时播放工具交互帧、返程显示实际携带资源，并依据路径水平方向翻转精灵。
- 同对象连续点击可在UI聚合成`quantity=N`，但资源采集必须拆成N个完整循环：前往资源→采1份→返回StorageChest→Deposit→下一循环。
- 首版不存在`carryCapacitySnapshot`或携带容量玩法。
- 支持批量播种、批量收获和RecipeConfig驱动的制作合成。

## 4. 校验、Reservation与激活

- 入队只做完整校验、Reservation和可达性验证，不冻结耗时。
- 任务真正轮到队首激活时，服务端读取工人当前属性和PlayerCharacter技能树，重新执行确定性路径计算，并冻结该ACTIVE任务的travel/work/return时间。
- 已ACTIVE任务不受后续属性变化影响；QUEUED任务可享受后续技能树变化。
- 所有输入、输出、建筑要求、数量和时长必须读取RecipeConfig；例如当前木板配方为木材3→木板1，代码不得硬编码。
- 制作建筑不预约未来工位时间段，不限制单建筑同时制作人数；最多3名工人可在不同interaction point工作，制作期间占用对应工人。

## 5. currentCell与任务结束位置

- 下一任务一律从服务端`IslandWorker.currentCell`激活并计算。
- 采集和收获在Deposit后结束于StorageChest交互格。
- 播种结束于对应农田交互格；批量播种结束于最后一块田。
- 制作结束于建筑交互格，成品直接进入StorageChest，不进入RETURNING。

## 6. 生命周期与异常

- 状态集合：`QUEUED / TRAVELING / WORKING / RETURNING / DEPOSITING / COMPLETED / SKIPPED / CANCELLED`，不存在`WAITING_RESOURCE`。
- 所有任务入队前完成校验和Reservation；运行异常直接`SKIPPED`、释放未消费Reservation并继续队列。
- 每名工人最多保留20条终态任务历史，所有未完成任务始终保留，防止长期账号的任务JSON无界增长。
- 工人任务、资源恢复、作物成长和制作全部使用服务端绝对时间离线FastForward。
- 服务端在任务激活时一次返回完整冻结Plan；客户端本地连续播放整项任务，只在任务预计结束时同步权威状态，禁止固定周期重建地图造成位移卡顿。
- 单次请求最多处理500个离线状态转换；达到上限时保存最后已处理时刻，下次请求确定性续推，不伪造“已推进到serverNow”。
- 作物视觉阶段由`plantedAt / readyAt / serverNow`在客户端推导；离线时间轴不生成`CROP_GROWTH_STAGE_CHANGED`，只处理影响状态或经济的事件。

## 7. 权威路径

- 服务端在21×35 IslandLandGrid上使用固定邻居顺序、固定成本与Tie-break的确定性寻路。
- Godot `AStarGrid2D`仅负责客户端路径预览和移动表现，不能决定完成时间、产出或最终状态。
- 每次任务激活后保存服务端路径、成本、属性快照、travel/work/return/deposit时长和配置版本，供在线同步与离线FastForward共同使用。
